# Effective steps and strategies for studying things from difficult classes

## 1. Go over lecture slides and make mind maps

This also involves taking and writing down any and all questions to ask in the next class

This also involves asking your self possible exam questions.  

Write those down in different colors, so that you only need to go over them before the exam for review

If it's becoming too hard to come up with questions, just write one that summarizes the concept and one really technical and hard one.

## 2. Solve exercise questions

Again, record all questions and get them resolved in exercise questions.

Mark which ones were tough and worth going over for exams.

## 3. Review mind-maps and notes from class, then solve exercise questions for exam

This is arguable the hardest bit.

It is difficult to know how deep the questions will be, especially given how vast the syllabus can be.

## 4. Solve past exam questions

## Review everything weekly
