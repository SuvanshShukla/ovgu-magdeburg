# activate venv

use the following command

```bash
source bin/activate
```

## For windows

```powershell
venv\Scripts\activate
```

Also worked for me:

```powershell
.\bin\activate
```

## Create venv

```bash
python -m venv /path/to/venv
```

This will create a "venv" named "venv" at your specified path.  
To change the name change `path/to/venv` to `path/to/custom-venv`.
