There may be cases where you must use different git credentials when cloning certain repos. Like University git repositories may require using a git account created using a university Email-ID.

To clone such repositories, mention your Git username in the cloning URL, like below:

```bash
git clone https://USERNAME@github.com/owner/repo.git
```

After this Git may ask you to enter your password. Once you do that you should be able to use it normally.
